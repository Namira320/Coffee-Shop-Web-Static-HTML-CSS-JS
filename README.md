## 📌 1. About the Project
**Classic Coffee** is an interactive static web platform developed to provide a digital experience for exploring coffee menus and products. This website features an elegant dark-themed UI design, complete with responsive navigation, product catalogs, an interactive location map, and a contact form.

---

## ✨ 2. Main Features
* **Hero Section & Navigation:** Features an attractive welcome banner with responsive main navigation links (*Home*, *About Us*, *Menu*, *Products*, *Contact*).
* **About Us:** A narrative section explaining the commitment and service quality of the coffee shop.
* **Menu Catalog:** Displays various coffee beverage variants (such as *Espresso*, *Cappuccino*, *Latte*, *Americano*, *Mocha*, and *Macchiato*) complete with their prices.
* **Featured Products:** Showcases high-quality coffee bean selections (*Robusta Brazil*, *Arabika Blend*, *Primo Passo*, *Aceh Gayo*, *Sumatra Mandheling*, etc.).
* **Contact & Location:** Integrated interactive location map and message form for visitors to send inquiries.

---

## 🛠️ 3. Tech Stack
This project is built using pure frontend web technologies:
* **Markup:** HTML5
* **Styling:** CSS3
* **Interactivity:** JavaScript (`script.js`, `app.js`)
* **Assets:** SVG & Icons / Vector Graphics
